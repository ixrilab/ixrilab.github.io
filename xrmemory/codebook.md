# XRMemory 원문 판정 체크표

기준일: 2026.11.04 · 버전: XRMR-SCOPE-DRAFT-20261104-1 · 상태: 연구팀 사례 보정 전 운영안

## 1. 판정 구조

**유형 사이는 OR, 유형 안의 요건은 AND다.** C0–C3 중 한 유형 이상의 요건을 원문 근거로 확인하면 연구 범위에 맞는 경로가 있다. 한 유형의 이름을 선택하는 것만으로 충족하지 않는다. 여러 유형에 해당할 수 있다. C1의 마지막 참여 조건은 공간 탐색 또는 콘텐츠 상호작용 중 하나면 된다.

포함 경로와 전체 적격성은 구별한다. 문헌군별 서지 범위·중복·출판 형식·언어·원문 접근 처리도 확인해야 하며, 미정 운영 항목은 아래에 명시했다. C1의 전체 구현 요건을 C0/C2/C3에 적용하지 않는다.

## 2. 원문에서 확인하는 순서

- 논문 ID·제목, 코더·날짜, 원문과 적용 기준의 버전을 적는다.
- 관련된 유형을 열고 각 항목을 근거 확인 / 미충족 / 확인 필요로 구분한다. 미체크는 미충족이 아니다.
- 근거 확인 항목에는 PDF 쪽수·절·그림·표와 관찰 내용을 남긴다. 부재 판단에는 확인 범위도 적는다.
- 한 유형을 충족하면 범위 경로가 있다. 추가로 해당하는 유형도 기록한다.
- 모든 경로를 미충족으로 판단할 때는 다른 포함 경로를 놓치지 않았는지 확인한다. 해결되지 않은 경로를 임의로 미충족으로 바꾸지 않는다.

## 3. 범위 판단과 기록

| 확인 상태 | 범위 판단 |
|---|---|
| 한 경로 이상 충족 | 연구 범위에 맞는 경로가 있음. 문헌군별 서지 조건을 확인하고 원문 판정을 남김 |
| 확정된 충족 경로 없음, 확인할 정보가 남음 | 범위 판단 미완료. 이를 자동 포함·제외로 바꾸지 않음 |
| 모든 경로 미충족을 확인 | 범위 미충족의 원문 근거와 확인 범위를 남김 |

이는 운영 논리의 초안이다. 근거 부족의 보류·자료 보완·총괄 검토 및 최종 미해결 종료 방식(D24)은 아직 사용자 확인 전이다. 단순한 Future work 언급 등 미충족이 확인된 경우와 자료 부족을 구별한다.

## 4. 포함 여부와 별도로 코딩할 항목

- 공간 적응·콘텐츠 반응의 수준, AI·룰 기반 구현 방식.
- 원기록·새 생성 부분의 사용자 구분 표시. 원천 연결과 표시 기능은 별도다.
- 원천 자료의 유형, 인물 충실도·회상 정확성의 평가와 한계.
- 적용 대상에는 같은 항목을 확인하고 미지원·미보고·해당 없음을 구별한다. 평가 항목은 코더가 임의로 생략해도 되는 항목이라는 뜻이 아니다.
- 구현 기능을 평가하지 않은 C0/C3의 X/Y는 N/A로 구별하고 0으로 대체하지 않는다.

## 5. 문헌 범위와 적용 전 확인

- 경험적 baseline은 2021–2025다. C0 개념·역사 문헌은 별도 범위로 관리한다.
- 2026 문헌은 별도 갱신 검색으로 기록하며 기존 분모에 자동 추가하지 않는다.
- 중복·출판 형식·언어·원문 미확보 처리의 기존 규칙을 대조한다. 언어 문구의 충돌은 미해결이다.
- C0 개념 문헌, 경험적 연구, 기술 역량 지도의 적용 대상 수를 구별한다. 역할이 중복돼도 고유 문헌 수를 중복 집계하지 않는다.
- 대표 10–15편의 인간 사례 보정과 전체 규칙·행정 게이트 명세를 완료한 뒤 본 적용한다. 이 체크표가 완료된 신뢰도 검증을 뜻하지 않는다.
- 기존 인간 판정·원자료·X/Y·분모는 보존하고, 본 적용 전 old/new·이유·영향 기록·검토자·날짜를 갖춘 amendment에 연결한다.
